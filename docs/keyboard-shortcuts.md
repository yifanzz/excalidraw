# Keyboard Shortcuts

## Custom Shortcuts (yifan-patch)

| Shortcut | Action |
|----------|--------|
| Shift+S | Cycle stroke style: solid → dashed → dotted |
| Shift+W | Cycle stroke width: thin → bold → extra bold |
| Shift+A | Cycle text horizontal alignment: left → center → right |
| Shift+T | Cycle text vertical alignment: top → middle → bottom |

Note: Shift+S overrides the upstream eye dropper for stroke color.
